개인정보처리방침

시행일: 2026-11-24

1. 수집하는 정보

  • 시청자: 업로드한 이미지, 직접 입력한 제작자 이름·컨셉·설명·프롬프트, 접속 IP, 브라우저에 저장되는 기기 식별값.
  • 방장(관리자): 관리자 로그인 확인용 구글 계정 이메일.

2. 이용 목적

  • 이미지와 입력 정보: 팬아트를 방장의 구글 드라이브에 저장하고 검수·공개하기 위해.
  • IP와 기기 식별값: 도배·악성 업로드 차단 등 악용 방지를 위해서만.

3. 구글 사용자 데이터

이 서비스는 방장 본인의 구글 계정 권한으로 방장의 구글 드라이브에 폴더와 파일을 만들고 옮깁니다. 이 권한은 팬아트 저장·검수 외의 목적으로 쓰지 않으며, 구글 사용자 데이터를 제3자에게 판매하거나 제공하지 않습니다. 관리자 로그인에는 이메일 주소만 받아 허용된 계정인지 확인합니다.

이 서비스의 구글 API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 보관 기간

  • IP·기기 식별값·업로드 기록: 30일 뒤 자동 삭제.
  • 승인된 이미지: 방장의 드라이브 공개 폴더에 보관. 반려된 이미지는 삭제.

5. 제3자 제공

수집한 정보를 판매하거나 제공하지 않습니다. 운영에 다음 서비스를 사용합니다: Google Cloud(서버·데이터베이스), Google Drive(이미지 저장), Cloudflare Turnstile(봇 확인), Discord(방장에게 알림, 업로드 정보 요약만 전달).
